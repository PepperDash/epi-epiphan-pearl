# epi-epiphan-pearl

PepperDash Essentials Plugin for Epiphan Pearl Devices

This plugin provides integration with Epiphan Pearl video capture and streaming devices for use with Crestron 3-series and 4-series control processors.

## Features

- Schedule management for recordings
- Event handling and monitoring
- HTTP communication with Epiphan Pearl devices
- Support for both secure and standard connections

## Installation

For 3-series systems, use the .cplz file from the 3Series build.
For 4-series systems, use the .nupkg file from the 4Series build.

## Configuration

Configure the plugin through the Essentials configuration system with the appropriate device settings and communication parameters.
